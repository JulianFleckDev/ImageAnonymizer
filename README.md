# ImageAnonymizer
Image privacy toolkit to remove metadata from images and make unwanted automated visual tracking more difficult.

!Important:
I created the following tools to protect the privacy of individuals acting for non-commercial purposes. 
They are not intended for business owners who wish to use these tools to hide the unlawful origin of their images in order to profit from them.

Meta Data Cleaner:
Drag the script into the directory containing the .png files you want to optimize. The program automatically searches for all .png files in that directory and in all subdirectories. 
The old files will be overwritten and replaced with the file without metadata.

Visual Tracking Recreate:
Drag the script into the directory containing the image you want to optimize. Change the input name in the script to the name of the image, or rename the image to pic.png. 
The script first converts the image to WebP and then to JPG at 80% quality. After that, the image is reduced in size by 5% and then enlarged by 5.28%. 
A small white border is added around the image, and it is rotated slightly by 0.3 degrees.
